# Repository Map

This file is a lightweight guide to the main areas of the repository.

## Main Areas

- `mobile_app/`: Flutter mobile app.
- `admin_dashboard/`: Flutter admin dashboard.
- `backend_and_cloud/`: Firebase, Cloudflare, backend code, rules, functions, and backend tests.
- `docs/`: project documentation and status notes.
- `testing_tools/`: local test helpers and validation utilities.

## Notes

- Use this map together with `docs/current-project-status.md` when orienting on a task.
- Keep this file brief and current; it is meant for fast navigation, not full documentation.
